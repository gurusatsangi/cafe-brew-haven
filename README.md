# ☕ Brew Haven

Brew Haven is a modern restaurant website template built with Next.js, React, TypeScript, and Tailwind CSS.

It is designed for restaurants, cafés, bakeries, and other food businesses, providing a clean user experience with features such as menu browsing, shopping cart, WhatsApp ordering, table reservations, and a contact form.

---

## Features

- Responsive Design
- Restaurant Menu
- Shopping Cart
- WhatsApp Ordering
- Table Reservation
- Contact Form
- Email Integration
- SEO Friendly

---

## Purpose

This project was developed as a reusable restaurant website template that can be customized for different food businesses by updating branding, menu items, images, contact details, and business information.
