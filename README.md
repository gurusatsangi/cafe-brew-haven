# ☕ Brew Haven

A modern and responsive café & restaurant website built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS**.

🌐 **Live Demo:** https://cafe-brew-haven-nine.vercel.app

---

## ✨ Features

- 🍽️ Modern Restaurant Landing Page
- 📖 Interactive Menu
- 🛒 Shopping Cart
- 🛍️ Floating Cart Drawer
- 📅 Table Reservation
- 💬 WhatsApp Ordering
- 📧 Contact Form (Resend)
- 📍 Google Maps Integration
- 📱 Fully Responsive Design
- ⚡ Vercel Analytics
- 🔍 SEO Optimized
